# OpenCart – Manual QA Testing 📋🧪

## 📌 Project Overview
This repository contains **manual testing documentation** for the OpenCart e-commerce website.  
The work focuses on creating a **Test Plan** and **Test Cases** to validate core website functionalities using **Manual Black-Box Testing**.

---

## 📂 Documents Included

### 📝 Test Plan
The Test Plan defines:
- Testing objectives
- Testing scope (In Scope / Out of Scope)
- Testing types and techniques
- Functional & non-functional requirements
- Assumptions and dependencies
- Entry & exit criteria
- Test schedule, risks, and metrics

---

### ✅ Test Cases
A set of structured test cases covering:
- User Registration & Login / Logout
- Product Search & Navigation
- Product Details Page
- Wishlist (Add / Remove)
- Shopping Cart (Add / Remove / Update)
- Basic UI validation

Each test case includes:
- Test Case ID
- Title
- Precondition
- Steps
- 	Expected Results

---

## 🔍 Testing Type
- Manual Testing  
- Black-Box Testing

🖥️ Testing was performed on a local OpenCart environment (XAMPP)
---

## 📦 Outcome
- Test Plan completed
- Test Cases written and organized
- Core OpenCart flows documented clearly
